# v0.4.0 Gap Analysis: "Runtime is Kernel, Agent is Thread"

> **Tanggal**: 2026-08-17  
> **Prinsip**: Runtime bertanggung jawab penuh atas penjadwalan. Agent hanya executor disposable (seperti thread di OS).

---

## 🎯 Prinsip Desain (ares-runtime.md)

```
Agents are not orchestrated. They are scheduled.

Agent decides; Kernel enforces.
```

**Agar prinsip ini terwujud, HARUS:**
1. ✅ Runtime membuat dan mematikan Agent
2. ✅ Runtime assign task ke Agent (melalui Fabric.Schedule)
3. ✅ Runtime jalankan Agent step-by-step (melalui Fabric.RunQuantum)
4. ✅ Runtime recover Agent setelah crash
5. ❌ Agent TIDAK BOLEH memiliki event listener mandiri yang memicu eksekusi

## 🔴 GAP 1: Dual-track tidak aktif default

**File**: `cmd/ares/kernel.go`

```go
// Masalah: Policy default tetap LEGACY
func wireKernelPolicy(...) {
    if strings.ToLower(strings.TrimSpace(cfg.Kernel.Policy)) != "taskfabric" {
        log.Printf("kernel: policy=legacy (default)")  // ← INI MASALAHNYA
        return
    }
    flipKernelToTaskFabric(ctx, kernel, subAgents)
}
```

**Dampak**: 
- Task dispatcher tetap menggunakan Leader agent dispatching
- AgentFabric/Fabric tidak dipakai untuk penjadwalan aktual
- Kernel adalah "observer" saja, bukan scheduler

**Fix Required**:
```go
// Default harusnya TASKFABRIC, bukan LEGACY
flag := agentipc.NewPolicyFlag(agentipc.PolicyTaskFabric)  // ← UBAH INI
```

## 🔴 GAP 2: Agent tetap punya event listener mandiri

**File**: `internal/agents/sub/agent.go:346`

```go
// Ini melanggar prinsip "Kernel schedules, agent executes"
func (a *subAgent) StartEventListener(ctx context.Context) error {
    // Agent subscribe sendiri ke EventStore
    subCh, err := a.eventStore.Subscribe(ctx, ...)
    
    // Agent jalankan task sendiri saat dapat event
    go func() {
        for {
            case ev := <-subCh:
                a.processScheduledEvent(ctx, ev)  // ← INI YANG SALAH
        }
    }()
}
```

**Dampak**:
- Agent bisa menjalankan task TANPA melalui Kernel scheduling
- Double execution: Kernel dispatch + Agent self-dispatch
- Breaks invariant: "Agent decides; Kernel enforces"

**Fix Required**:
```go
// HAPUS atau DISABLE StartEventListener
// Agent HARUS menunggu dipanggil oleh Kernel через RunQuantum
func (a *subAgent) StartEventListener(ctx context.Context) error {
    return errors.New("ares: self-dispatch is disabled; use Kernel scheduling")
}
```

    // ... existing code ...
    
    // NEW: Notify all tasks that depend on this one

func (f *Fabric) notifyDependents(completedID string) {
    for id, t := range f.tasks {
        for _, dep := range t.Dependencies {
            if dep == completedID {
                // Task might now be ready
                f.emit(EventTaskReady, id)
            }
        }
    }
}
