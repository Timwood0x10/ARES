### P0-2: Spawn 生命周期原语

**设计依据**: ares-runtime.md §10 "spawn 是 syscall，不是 orchestration API"
```go
type SpawnSpec struct {
    Task         TaskSpec
    Capabilities []string
    Context      ContextSpec  // parent 的 snapshot / selected projection
    Resources    ResourceSpec
}

// 现有实现缺失，需要新增：
func (f *Fabric) Spawn(parentID, childID string, spec *SpawnSpec) error
func (f *Fabric) Suspend(agentID string) error
func (f *Fabric) Resume(agentID string) error
func (f *Fabric) Kill(agentID string) error
```

**关键设计决策**:
```go
// spawn establishes provenance, not hierarchy
// A creates B 只建立生命周期来源，创建后 A ≡ B（同级）

type SpawnRecord struct {
    ParentID   string
    ChildID    string
    CreatedAt  time.Time
    Provenance bool  // true = 由 Agent 主动 spawn，false = 系统创建
}

// Process Tree ≠ Scheduling Graph
// 父子关系树（Lifecycle 看）与 Task 依赖图（Scheduler 看）并存不混
```

**实现建议**:
```go
func (f *Fabric) Spawn(parentID, childID string, spec *SpawnSpec) error {
    f.mu.Lock()
    defer f.mu.Unlock()
    
    // 1. 校验 parent 存在且存活
    parent := f.agents[parentID]
    if parent == nil || parent.State != AgentRunning {
        return ErrParentNotAlive
    }
    
    // 2. 校验 capability 匹配
    if !f.checkCapabilities(childID, spec.Capabilities) {
        return ErrCapabilityMismatch
    }
    
    // 3. 创建子 Agent（同级，非层级）
    child := &Agent{
        Identity:     childID,
        Capabilities: spec.Capabilities,
        State:        AgentIdle,
        ParentID:     parentID,  // 仅记录 provenance
    }
    f.agents[childID] = child
    
    // 4. 创建 Task（如果 spec 包含）
    if spec.Task != nil {
        if err := f.Create(spec.Task); err != nil {
            delete(f.agents, childID)  // rollback
            return err
        }
    }
    
    // 5. 记录事件
    f.record(&Agent{ID: childID}, EventAgentSpawned)
    return nil
}
```

## 🟠 P1 - 可靠性增强

### P1-1: Recovery 插件实现

**设计依据**: ares-runtime.md §10 将 Chaos 升级为 Recovery
```go
// internal/ares_runtime/recovery_plugin.go
type RecoveryPlugin struct {
    fabric   *Fabric
    store    ares_events.EventStore
    registry *AgentRegistry
}

func (r *RecoveryPlugin) Recover(ctx context.Context, taskID string) error {
    // 1. 从 Event Store 重建 Task 状态
    events := r.store.QueryByStream(taskID)
    
    // 2. 重放事件序列
    state := reconstructState(events)
    
    // 3. 重新 acquire 或 suspend
    if state.IsComplete() {
        return nil  // 已完成，无需恢复
    }
    
    if state.IsSuspended() {
        return r.resumeTask(taskID)
    }
    
    return r.requeueTask(taskID)
}
```

**恢复策略**:
| 场景 | 策略 | 说明 |
|------|------|------|
| Agent 崩溃 | Requeue | Task 回到 READY，等待新 Agent acquire |
| Agent 超时 | Suspend + Retry | 保留 checkpoint，降低优先级重试 |
| Task 失败次数超限 | Fail + Notify | 标记失败，通知上层处理 |

### P1-2: Lease Epoch 增强

**设计依据**: ares-runtime.md §6 "leaseEpoch（fencing token）"
```go
// 现有实现：epoch 是 uint64，单调递增
// fabric.go:138 epoch, err := f.Acquire(id, agentID, ttl)

// 建议增强：支持 epoch 回滚检测
type Lease struct {
    Epoch    uint64
    Owner    string
    TTL      time.Duration
    Created  time.Time
    Expanded bool  // 是否被 renew 过（防时钟回拨）
}

func (f *Fabric) Acquire(id, agentID string, ttl time.Duration) (uint64, error) {
    f.mu.Lock()
    defer f.mu.Unlock()
    
    task := f.tasks[id]
    if task.Owner != "" && task.Lease.Epoch > 0 {
        // 防止 epoch 回绕攻击
        if task.Lease.Expanded {
            return 0, ErrEpochRollback
        }
    }
    
    newEpoch := f.epoch + 1
    f.epoch = newEpoch
    
    task.Owner = agentID
    task.Lease = &Lease{
        Epoch:    newEpoch,
        Owner:    agentID,
        TTL:      ttl,
        Created:  f.now(),
        Expanded: false,
    }
    
    f.record(task, EventTaskAcquired)
    return newEpoch, nil
}
```

### P1-3: Cooperative Preemption 完善

**设计依据**: ares-runtime.md §4 "Cooperative Preemption，不是 OS 硬抢占"
```go
// 现有实现：steal.go 已有 Work Stealing
// 需要新增：Preemption（高优先级抢占）

func (f *Fabric) Preempt(taskID, reason string) error {
    f.mu.Lock()
    defer f.mu.Unlock()
    
    task := f.tasks[taskID]
    if task.State != TaskRunning {
        return ErrIllegalState
    }
    
    // 1. 保存 checkpoint（cooperative，不中断执行）
    checkpoint := task.Checkpoint
    if checkpoint == nil {
        return ErrNoCheckpoint
    }
    
    // 2. 释放 lease
    task.State = TaskReady
    task.Owner = ""
    task.Lease = nil
    task.Checkpoint = checkpoint  // 保留用于恢复
    
    // 3. 记录事件
    f.record(task, EventTaskPreempted)
    
    // 4. 通知 Scheduler 重新调度
    f.scheduler.NotifyPreempted(taskID, reason)
    
    return nil
}
```

## 结论

v0.3.0 完成了"单 Agent 进化闭环"，v0.4.0 应该完成"多 Agent 协作运行时"的核心能力：

1. **IPC 通信** → Agent 间协同的基础
2. **Spawn 生命周期** → 实现"同级认知进程"模型
3. **Checkpoint 持久化** → 实现"durable intent"保证
4. **Recovery** → 实现"Agent 死亡 ≠ Task 死亡"

这些功能的完成将真正兑现 ares-runtime.md 的设计愿景：**Agents are not orchestrated. They are scheduled.**
